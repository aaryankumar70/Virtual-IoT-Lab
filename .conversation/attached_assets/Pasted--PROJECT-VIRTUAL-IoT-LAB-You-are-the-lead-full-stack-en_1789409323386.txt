# PROJECT: VIRTUAL IoT LAB

You are the lead full-stack engineer building a serious MVP/prototype of a browser-based virtual IoT electronics laboratory.

The goal is NOT to make a static 3D visualization.

The goal is to build the foundation of a platform where users can:

1. Place virtual IoT boards and electronic components into a 3D workspace.
2. Wire components together.
3. Program supported virtual boards.
4. Run the program.
5. See the virtual hardware respond in real time.
6. Inspect serial output and simulation state.
7. Save/load projects.
8. Eventually use the same platform to transition from virtual hardware to real hardware.

Think of the long-term product as:

Wokwi + Tinkercad Circuits + a 3D engineering workspace + an extensible IoT simulation engine.

For this first version, DO NOT attempt to support every Arduino/ESP32/Raspberry Pi feature.

Build a small, extremely solid core that can be expanded later.
